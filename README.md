# 🚉 駅名クイズ

日本全国の駅名データを使ったブラウザで動作するクイズアプリ。2つのゲームモードを収録。

## モード一覧

### 🎯 古今東西モード (`kokin.html`)

フィルタで絞り込んだ駅名を、テキスト入力で次々と答えていくモード。

- **入力判定**: 正式名・別名いずれでも正解扱い（大文字小文字・空白は正規化）
- **ヒント**: トグルで未解答駅の枠を表示可能
- **ギブアップ**: 途中で降参後、「続きから再開」で再挑戦可能
- **結果表示**: 全解答一覧を正解/未解答で色分け表示

### ❓ クイズモード (`quiz.html`)

駅名が出題され、都道府県・路線・鉄道会社を答えるモード。

| 出題形式 | 内容 |
|---|---|
| 駅名 → 都道府県（選択式） | 4択から選ぶ |
| 駅名 → 都道府県（記入式） | テキスト入力（接尾辞「都/道/府/県」省略可） |
| 駅名 → 路線（選択式） | 4択から選ぶ |
| 駅名 → 鉄道会社（選択式） | 4択から選ぶ |

- **出題数**: 10問 / 50問 / 100問 / 無限
- **結果一覧**: 終了後に正解/不正解をまとめて確認可能

## 共通フィルタ機能

両モードで同じフィルタ UI を使用。AND/OR を切り替えて複数条件を組み合わせ可能。

| フィルタ種別 | 説明 |
|---|---|
| 都道府県 | 複数選択可 |
| 地方 | 複数選択可（東北、関東、中部、北陸、甲信越、東海、近畿、中国、四国、九州） |
| 鉄道会社 | 複数選択可 |
| 路線 | 複数選択可 |
| 路線数 | 乗り入れ路線数（以上・以下・等しい） |
| 鉄道会社数 | 乗り入れ鉄道会社数（以上・以下・等しい） |
| 文字数 | 駅名の文字数（以上・以下・等しい） |
| 始まりの文字 | 前方一致 |
| 終わりの文字 | 後方一致 |
| 含む文字 | 部分一致 |
| その他 | 特殊条件（ひらがなを含む、カタカナを含む、漢数字を含む、同じ文字が二回以上含まれる、方角を含む、色の漢字を含む、動物の漢字を含む、植物の漢字を含む、同名の駅が他にある、他都道府県名を含む、都道府県名を含む、旧国名を含む、非JR駅、JR駅） |

```
    └── quiz.js           # クイズモードのロジック
```
